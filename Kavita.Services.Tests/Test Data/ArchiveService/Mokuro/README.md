# Mokuro test archive

`MokuroTest.cbz` is a two-page synthetic comic for automated and manual Mokuro testing. The page artwork consists only of generated geometric shapes and labels, and its OCR metadata is stored in `MokuroTest.mokuro` inside the archive.

The Mokuro page records are intentionally out of archive order so a manual test also verifies filename-based page alignment. Hovering or focusing each outlined OCR region should reveal selectable text within that region.

The fixture and its source metadata are dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
